# 企业网站管理系统 - 用户操作手册

## 1. 系统概述

企业网站管理系统是一套功能完善的企业网站解决方案，包含后台管理系统和前台展示网站两大模块。

### 1.1 系统功能

- **内容管理**：新闻、产品、案例、Banner、单页管理
- **用户管理**：用户账号、角色权限管理
- **系统管理**：系统配置、留言管理、操作日志

### 1.2 技术架构

- 后端：ThinkPHP 8.0
- 数据库：SQLite 3
- 前端：Bootstrap 5 + jQuery

## 2. 快速开始

### 2.1 登录系统

1. 访问后台地址：`http://your-domain/admin`
2. 输入用户名和密码
3. 输入验证码
4. 点击"登录"按钮

默认管理员账号：
- 用户名：admin
- 密码：admin123

### 2.2 仪表盘

登录后进入仪表盘页面，可以查看：
- 系统统计数据（新闻、产品、案例、留言数量）
- 最新留言列表
- 最新新闻列表
- 快捷操作入口

## 3. 内容管理

### 3.1 新闻管理

#### 发布新闻
1. 点击左侧菜单"新闻管理"
2. 点击"发布新闻"按钮
3. 填写新闻信息：
   - 标题（必填）
   - 分类（必填）
   - 封面图片
   - 摘要
   - 内容（必填）
   - 作者、来源
   - 发布时间
   - 置顶、推荐选项
   - 状态
4. 点击"保存"按钮

#### 编辑新闻
1. 在新闻列表中找到要编辑的新闻
2. 点击"编辑"按钮
3. 修改新闻信息
4. 点击"保存"按钮

#### 删除新闻
1. 在新闻列表中找到要删除的新闻
2. 点击"删除"按钮
3. 确认删除

### 3.2 产品管理

#### 添加产品
1. 点击左侧菜单"产品管理"
2. 点击"添加产品"按钮
3. 填写产品信息：
   - 名称（必填）
   - 分类（必填）
   - 封面图片
   - 简介
   - 详情
   - 价格
   - 排序
   - 推荐选项
   - 状态
4. 点击"保存"按钮

### 3.3 案例管理

操作方式与产品管理类似，可以管理企业案例展示。

### 3.4 分类管理

1. 点击左侧菜单"分类管理"
2. 选择分类类型（新闻/产品/案例）
3. 添加、编辑或删除分类

### 3.5 Banner管理

1. 点击左侧菜单"Banner管理"
2. 添加首页轮播图
3. 设置标题、链接、排序

### 3.6 单页管理

用于管理"关于我们"、"联系我们"等静态页面内容。

## 4. 用户管理

### 4.1 用户列表

1. 点击左侧菜单"用户列表"
2. 查看所有管理员用户
3. 可以添加、编辑、删除用户
4. 可以启用/禁用用户

### 4.2 角色管理

1. 点击左侧菜单"角色管理"
2. 管理用户角色
3. 为角色分配权限

#### 分配权限
1. 在角色列表中点击"分配权限"
2. 勾选需要的权限
3. 点击"保存"按钮

## 5. 系统管理

### 5.1 系统配置

1. 点击左侧菜单"系统配置"
2. 配置网站基本信息：
   - 网站名称
   - Logo
   - SEO关键词
   - SEO描述
   - ICP备案号
   - 版权信息
3. 配置联系信息：
   - 公司名称
   - 地址
   - 电话
   - 邮箱
4. 点击"保存配置"

### 5.2 留言管理

1. 点击左侧菜单"留言管理"
2. 查看用户留言
3. 可以查看详情、回复、删除留言

### 5.3 操作日志

1. 点击左侧菜单"操作日志"
2. 查看系统操作记录
3. 可以按条件筛选日志
4. 超级管理员可以清空日志

## 6. 前台网站

### 6.1 首页

展示Banner轮播、推荐产品、最新新闻、推荐案例、联系信息。

### 6.2 新闻中心

展示新闻列表，支持分类筛选，点击可查看详情。

### 6.3 产品展示

展示产品列表，支持分类筛选，点击可查看详情。

### 6.4 案例展示

展示案例列表，支持分类筛选，点击可查看详情。

### 6.5 关于我们

展示公司介绍信息。

### 6.6 联系我们

展示联系方式，提供在线留言表单。

## 7. 常见问题

### Q: 忘记密码怎么办？
A: 联系超级管理员重置密码。

### Q: 图片上传失败？
A: 检查图片格式（支持jpg/png/gif/webp）和大小（不超过2MB）。

### Q: 如何修改网站Logo？
A: 在"系统配置"-"基本设置"中上传新Logo。

### Q: 如何备份数据？
A: 复制 `runtime/database.db` 文件即可备份数据库。
